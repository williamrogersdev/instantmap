# Instant Map in SvelteKit

SvelteKit 3 with Svelte 5. The server renders the first map image, the browser loads the interactive map on top of it.

```sh
bun install
bun run dev
```

Set `INSTANTMAP_SRC` to use another image server. The default is `https://instantmap.org`.

Guide: https://instantmap.org/docs/frameworks/sveltekit
