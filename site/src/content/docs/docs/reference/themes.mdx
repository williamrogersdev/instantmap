A theme is a palette of 36 colour tokens. The server draws the map with them and the browser draws markers, popups and controls with them, so the still image and the live map always match.

Pick a theme, then override any token:

```html
<instant-map theme="midnight" colors="accent:ff5a5f,cluster:ff5a5f"></instant-map>
```

```js
map.theme = "paper";
map.colors = { water: "#9fd3ff", accent: "#ff5a5f" };
```

```ts
staticUrl({ center, zoom, width, height, theme: "mono", colors: { accent: "#0a6fd6" } });
```

Colours are `#rrggbb` or `#rrggbbaa`. In the `colors` attribute and the URL, leave out the `#`.

Changing the theme or colours on a live map reloads the tiles in the new colours.
