Instant Map

A map that arrives as one image, then wakes up when you touch it. No map library on page load.

Source on GitHub

Drag, scroll or pinch to explore. The picture above loaded with no JavaScript; tiles take over on your first touch.

0 KBJavaScript before you touch the map
~5 KBgzipped client once you do
1 requestfor the first view, listings included

Three tiers, pay for what you use

Still

An <img> rendered at the edge from vector tiles by a Rust renderer. Labels, roads, water and your markers in one cached JPEG.

Glide

A small custom element. Pan, zoom and pinch over raster tiles from the same renderer, so the picture never changes style.

Vector

Later, for apps that need rotation or live restyling. Most pages never load it.

Use it

<instant-map center="-96.95,32.85" zoom="9" markers="-96.8,32.78;-97.33,32.75">
  <img src="/static?center=-96.95,32.85&zoom=9&size=1280x560&markers=-96.8,32.78;-97.33,32.75" alt="Map">
</instant-map>
<script type="module" src="/instant-map.js"></script>
